# Project Summary

## Machine Learning Model Overview

This project implements a convolutional neural network (CNN) to classify waste into categories such as biodegradable, e-waste, glass, metal, paper, and plastic. The dataset is organized by waste type, and the model is trained using images from these folders. The workflow includes scripts for training (`train.py`), prediction (`predict.py`), accuracy evaluation (`accuracy_eval.py`), and utility functions (`utils.py`). The trained model is saved as `waste_model.h5` in the model directory. Reports document model creation and deployment. The project aims to automate waste sorting for environmental sustainability.

## Project Summary

Gratify Ads is a full-stack web application designed to facilitate waste management and video content handling. The project features:

- **API Functionality**: RESTful endpoints for uploading, downloading, and managing videos and waste data.
- **User Management**: Components and APIs for creating and managing users.
- **Waste Management**: APIs and UI components for tracking, uploading, and categorizing waste, integrated with the ML model for automated classification.
- **Video Management**: Upload, download, and overview features for video content, including support for Cloudinary integration.
- **Dashboard & UI**: Modern dashboard with tabs for overview, bins, waste, videos, uploads, and API access.
- **Database Integration**: Utilizes a database for storing user, video, and waste information.
- **Documentation**: Includes API functionality documentation and model creation/deployment reports.

The project is structured for scalability and maintainability, supporting environmental sustainability through automated waste sorting and efficient content management.
